# parking management system-parkzone
 Parking Management System 🚗  A web-based Parking Management System   developed using   Python, Flask, HTML, Pandas, and Microsoft Excel. This mini project helps manage vehicle parking records and automatically calculates parking fees based on the parking duration.   Features    Add new vehicle parking records   Record vehicle entry and exit times  Automatically calculate parking duration   Automatically calculate parking fees  Edit existing parking records   Delete parking records   Store and manage data using Excel   Simple and user-friendly web interface   Technologies Used    Python  Flask   HTML    Panda    Microsoft Excel    Project Purpose  The main purpose of this project is to provide a simple digital solution for managing parking information and reducing manual record keeping.  Project Type  Mini Project / Academic Project.
